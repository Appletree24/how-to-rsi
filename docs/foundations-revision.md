## 新实验提供什么

`labs/improver_lab.py` 实际执行解析器，不用预填分数或随机成绩模拟更新。同一个 `improve` 过程可修改 Solver 配置，也可修改 Improver 顺序；当前控制者在一次调用内冻结，返回的新版本在下一次调用接管。

三组比较为冻结改进器、配置自应用与全配置穷举。它记录嵌套训练成本、逐条结果及第二轮零收益；确认模板收益、分布变化退化和穷举成本优势同时保留。公开任务很小，不能用于真实模型性能、统计显著性或开放式 RSI 的主张。

新增六个测试覆盖补丁交互、不可变父版本、空修改计账、控制者快照、分布变化反转与多轮无收益。网页结果表直接来自代码执行；正文与 README 的手算数字另经核对。
