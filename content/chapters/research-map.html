研究笔记 / R5

自我改进的几类研究方法

Self-improvement 可以指答案修订、记忆积累、权重训练，也可以指程序搜索和搜索器更新。它们使用不同的反馈，改变系统的不同部分；读论文时应先确认修改对象。

路线与入口变化的对象与递归的关系优先做的对照
Self-Refine 同一任务上的答案迭代反馈并不自动积累可迁移的改进器同预算直接多采样、无反馈重写
Reflexion 语言反馈与经验记忆不用更新权重也可能改变后续行为清空记忆、打乱记忆、跨任务迁移
Voyager 技能库与探索任务积累可执行技能；须另证技能是否提高后续学习效率固定课程、移除技能检索、相同探索步数
STaR 生成推理数据后微调权重参数层自训练，不等于训练算法自动演化同规模外部数据、只筛答案、跨题型测试
MAML 便于适应任务的初始化显式优化“如何快速学”；外部元优化过程通常固定相同适应步数、随机初始化、任务族外迁移
AutoML-Zero 学习算法程序搜索训练算法；仍需说明搜索器是否变化随机搜索、搜索空间限制、计算预算对齐
ADAS agent 设计固定 meta-agent 也能产出更好的 agent；是重要外部优化基线冻结与更新改进器、相同模型与候选预算
STOP / DGM / HGM 代码改进器、agent、搜索与选择必须分别检查自引用、档案、估计器与控制策略见 R2 的固定改进器与完整搜索消融
POET 环境与解法共同演化任务分布也在变化；平均分跨轮次未必可比冻结环境、移除迁移、外部固定审计任务
FunSearch 由外部 evaluator 检验的程序程序搜索与 agent 自修改有共同组件，但不是同一主张固定搜索器、普通采样、候选与验证成本

元学习、程序搜索与课程生成

优化与统计：选择偏差、bandit 资源分配、best-arm identification、序贯检验。解决“测谁、测几次、何时停止”，而不只是“怎么生候选”。先做 R3 的选择偏差实验，再理解 HGM 为什么把展开与评估解耦。

系统与可复现性：内容寻址、确定的环境快照、幂等任务、故障分类、事件日志、预算调度。其价值是让算法比较成立。没有完整失败记录，再复杂的谱系统计也可能只统计幸存者。

开放式搜索与目标漂移：新颖性不等于用户效用，多样性也不保证持续改进。保持外部审计目标固定，分别报告覆盖、新颖性和任务效用；任务难度增加时不能直接比较原始通过率。

什么时候读哪一条

  • 想做 Agent Evaluation：优先 R3/R4、HumanEval 的指标、τ-bench 的可靠性、judge 校准。
  • 想做自改搜索研究：先复现固定预算基线，再进入 STOP、DGM、HGM 与开放式搜索。
  • 想做训练方向：先补优化、任务分布、数据筛选和遗忘，再读 STaR/MAML；不必从运行时插件入门。
  • 想做 harness 工程：围绕评分器隔离、任务执行和实验账本读 DSH；包名的熟练度不能替代实验设计能力。

这是一张按机制组织的入门地图，不宣称覆盖截至今天的所有论文，也不以论文年份决定优先级。每条新增路线必须解释它能帮助排除哪种错误结论。
