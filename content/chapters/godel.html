基础 / 02 · 证明与测量

自修改的接受条件：证明、经验评测与探索价值

一个补丁把解析器成功率从 0.80 提到 0.81，未来还剩 1,000 个请求。切换是否划算，取决于切换成本以及继续搜索的机会；候选是否值得保留，又取决于它能否通向更好的后代。Gödel Machine、STOP、DGM 与 HGM 对这些问题采用了不同的判断机制。本章从效用和切换条件出发，讨论形式证明、统计评测与搜索档案各自支持的结论。

规格、测试与证明的范围

补丁 strip() 的价值首先取决于规格。允许首尾空白时，接受 " 3s " 可能是修复；协议禁止空白时，同一行为就是回归。功能规格固定以后，延迟与资源成本仍可能改变发布收益。因此，“更好”需要相对于明确的输入环境、效用和时间范围来定义。

十条测试全部通过，只能确认这十个点上的行为，没有覆盖任意长度、Unicode 空白或资源耗尽。若输入域是一份固定的有限表，穷尽每一项便可得到这个有限域上的检查结论，但它依然不自动覆盖真实流量。形式证明则说明实现满足形式规格，规格是否正确表达用户意图仍需验证。统计证据、穷尽检查、形式证明各有量词，增加样本量并不能使它们无条件互换。

Gödel Machine 的状态、公理与效用

上一章用开发集分数决定是否保留候选：先运行，再比较。Gödel Machine 把顺序反过来——不修改，直到先证明修改更好。名字取自哥德尔的自指公式：机器要在描述自身的形式语言里推理并修改自身。它的可改代码 p 含两部分：与环境交互的初始求解器 e(1)（通常并非最优），和一个证明搜索器；两者都装在 p 里，因此都可能被重写。

论文把整机状态记为 s(t)：存储内容、软件 p、输入 x、输出 y 与当前时刻 time 编码在同一变量中，硬件按周期 t = 1,2,…,T 逐条执行指令。效用取剩余生存期的期望累计回报 u(s, Env) = E_µ [Σ r(τ) | s, Env]。这个定义顺手解决了一个记账问题：证明搜索消耗的周期本可用于行动，搜索成本直接计入同一个 u，无需另设“思考预算”。

要判断“改了更好”，机器得能推理自己的行为，因此 p(1) 内还编码公理系统 A：每条硬件指令如何改变 s（含指令指针）、各动作与输入的成本和回报、环境产生输入的先验假设（允许的分布集合 M）、算术与概率论公理、初始状态与初始代码自身，以及效用函数 u。把 p 的描述写进 p 并不循环——一段程序可以包含能打印自身的代码。搜索器能下的结论以 A 能表达且能推出的为限：环境的哪部分写进公理，保证就能覆盖哪部分。

初始机器的组成；对照论文图 1 的存储示意
s(t)：整机状态（硬件逐周期更新）
├─ p(t)：可改软件
│   ├─ e(1)：与环境交互的求解器
│   └─ 证明搜索器：调度证明技术，检查目标定理
├─ proof / switchprog：增长中的证明与候选重写
├─ x(t), y(t), time：环境输入、输出、当前周期
└─ 公理 A 与效用 u：以代码形式编码在 p(1) 内

证明搜索运行的是“证明技术”——本身也是程序，可读状态、推导并逐条输出定理，而非按长度枚举所有证明。初始搜索器 BIOPS 按各技术的先验权重分配运行份额，论文 §5 证明它达到 O() 阶最优；但 O() 只约束阶数，常数因子的慢可在日后用一次“被证明有益”的重写消除，包括重写 BIOPS 自己。某个证明技术一旦推出目标定理，check() 便把控制权交给候选 switchprog，后者可改写 p 的任意部分——求解器、搜索器，或两者一起（硬件保留变量除外）。

一个证明技术的一轮：六条专用指令中的四条（论文 §3.2）
get-axiom(n)         # 把第 n 条公理追加为 proof 中的定理
apply-rule(k, m, n)  # 用第 k 条推理规则作用于定理 m、n，追加新定理
set-switchprog(m,n)  # 把工作区 s_p 的一段设为候选重写程序
check()              # 若 proof 末条是目标定理：置 switchbit，转交 switchprog

# proof 只能由专用指令写入（定理追加、定理删除、状态转定理），
# 因而序列中不会出现非法定理；check() 与匹配本身也消耗周期，计入 u。

目标定理比较现在切换与继续搜索

§4.1 的全局最优定理依赖一个容易读漏的细节：目标定理比较的是“现在执行 switchprog”与“让 p 原样继续运行”。p 原样运行意味着证明搜索继续，未来还可能产生别的 switchprog。右边因此包含当前搜索过程将来找到更好改动的可能性与等待成本。论文的保证相对于给定公理、效用和该继续搜索分支成立；它不是“已枚举并击败所有可想象程序”，也不能外推为现实环境中的无条件最优。

目标定理的简化记法；对应论文式 (2)，省略形式编码
u[ s(t₁)⊕(switchbit = '1'), Env ]    ← 现在执行 switchprog
  >
u[ s(t₁)⊕(switchbit = '0'), Env ]    ← p 原样运行，证明搜索继续

证出后 check() 置 switchbit 并执行 switchprog。
没有找到证明，并不等于已经证明 switchprog 无益。

这条比较还自动覆盖递归：u 计的是整条未来轨迹，当前比较由此纳入了重写对后续自改的影响——§4.3 称所有元层级折叠进同一个定理，不必为“修改修改器的修改器”另设判定层。

开头的例子可以先作一个简化比较。假设每个成功请求贡献 1 单位效用，失败贡献 0，剩余请求 N=1,000；旧版 p₀=0.80，新版 p₁=0.81。忽略其他搜索机会，若切换开销折合为 c=20 单位效用，则 ΔU=N(p₁−p₀)−c=10−20=−10，不值得切换。这里 c 是效用损失，不能直接将 20 个被丢弃请求视为 20 个本来必成功的请求。若开销改成 c=2，则 ΔU=8，相对于固定旧版有正收益。

这个 ΔU>0 尚未满足目标定理的比较条件。继续搜索可能找到成功率 0.90 的方案，也可能把剩余时间耗尽；整条未来轨迹的效用取决于搜索成功概率、发现时刻和执行成本。以上 p₀、p₁、c 均为假设值，既非实测，也非公理推导的结果。若它们来自样本估计，发布判断还需处理估计的不确定性。

可证性、时间限制与自观测

可证性限制了搜索的范围。对任何一致且足够强、可表达基本算术的有效形式系统，都存在“真但证不出”的命题；某个重写确实有益，机器却可能永远无法证明。有限资源又进一步收紧范围：能证明、但来不及在有用时间内证完的改进，同样无法触发切换。论文借助不可判定性结果，说明可以构造出使目标定理不可证的病态环境与效用组合。不过，目标定理只要求比较两边大小，无需求出精确效用；证明某子程序提速一倍有益，并不要求知道精确的期望回报。

自观测也有实现成本。证明可以把 s 的当前内容直接转成定理（state2theorem）：环境输入只有运行后才知道，有些事实执行一次也比从初始状态推出更快。但读取正在变化的状态并不可靠——读指令指针的动作本身就改变指令指针，论文为此规定了读取协议与保留区。完整的自身描述并不自动带来对当前状态的可靠观测。

因此，被证明有益的修改只覆盖“能被 A 表达、又能在限时内证出”的子集。现实部署中的 API 漂移、用户目标变化和硬件故障，要么进入 A 和 u 的建模范围，要么留在保证之外。形式规格内的正确性不能直接推广为现实环境中始终有益。

论文中的最优性由目标定理和公理范围共同限定，无需枚举所有补丁，也不意味着证明永远无法触发。实际可行性取决于哪些假设能够形式化、哪些改动能及时获得证明，以及建模与证明本身消耗多少效用。

STOP 与 Gödel Agent 的经验路线

第一章的 I₀ → I₁ 对应另一种做法：运行候选改进器，看它能把下游程序改到什么程度。STOP 用调用语言模型的程序执行这类自应用，基础模型保持固定。它给出了经验搜索路线，不需要先证明每一次修改有益；相应地，有限任务上的得分也不提供 Gödel Machine 那样的形式保证。 Gödel Agent 走了另一条路：保留改写自身逻辑的自引用形式，但不设证明门槛，由语言模型在运行时按高层目标直接修改控制逻辑。

这里有两个预算：尝试多少个改进器，以及每个改进器获得多少下游改进机会。上一章训练用了 15 次整组评分，应用又用了 3 次。若只报告应用阶段，就把学习改进器的开销隐藏了。若训练好的策略能服务很多后续任务，训练成本可以摊销，但需要把使用次数明确列出。固定规则的穷举、随机搜索和人工策略都可能是必要的基线。

经验搜索降低了候选切换的门槛：证明成本可能使有限预算内一次切换都无法发生，受控任务上的评测则能提供可比较的观测。代价是抽样误差、选择偏差和评分器失真。工程上，明确的权限与接口不变量可以交给确定性检查，任务收益交给独立评测，发布流程再控制暴露范围。这些证据各有覆盖范围，测试结果无法提供对全部安全性质的证明。发布判断在 04 展开。

互补补丁与跨越低分中间态

假设一个代理有两个互补补丁：A 更换工具返回格式，B 更新读取这个格式的逻辑。单独装 A 或 B 都会破坏兼容性；同时安装才有收益。如果搜索器一次只改一个部件、且立刻丢弃所有退步候选，它到不了 A+B。也可以设计一次提交两个补丁的提议器；保留弱候选只是改变可达路径的一种办法。

下面的八位模拟器用一个有限搜索空间展示这种情形。前六位各加 1 分；第七、第八位单独出现时另扣 12 分，同时出现时另加 35 分。全零为 0 分，前六位全开为 6 分，所有位全开为 43 分。每次仅翻转一位，所以从 6 分走向 43 分必经 6−11=−5 分的状态。严格贪心不会接受这一步。

控件可以分别运行严格贪心与开放档案。只翻一位时，贪心到达 6 分后不会接受 −5 分；档案只要保留并再次选中这个低分节点，就有机会跨到 43 分。若一次同时翻转最后两位，贪心也能跨过去，可见障碍来自操作邻域与接受规则的组合。开放档案均匀选择父代，也可能将预算花在弱分支上；一次 60 代的轨迹既不能估计成功率，也不足以判定方法无效。模拟器没有语言模型或会更新的改进器，只展示搜索景观，不承担论文复现或递归收益验证。

DGM：让已经产生的代理参与后续修改

DGM 将可继续工作的代理保存在档案中，选择父代后执行自修改。经验分数引导父代选择；候选入档不要求先超过父代。论文还比较了“当前代理修改自己”与“始终由初始代理修改当前目标”，借此研究更新修改者的贡献。基础模型和外部档案管理并非都随代理一起改变。

这与上面的均匀采样模拟器有两个重要差别：论文使用有偏的父代采样规则，修改操作也由代理产生。它的无开放探索对照保留最新有效后代，并不等同于模拟器的“只接受不降分”规则。把交互演示当作论文复现，会同时误读搜索方法和消融结论。

档案保存后续搜索的起点，发布版本则承担当前的用户任务。允许档案保留较弱候选，可以增加搜索路径；线上版本不必随之降级。两个对象具有不同的准入条件，下一章将用版本与运行记录表达这种区分。

HGM：在评估与展开之间分配预算

HGM 将展开与评估分开调度，并用支系数据估计未来搜索价值。当前分数、支系的合并通过率、未来最佳后代的期望表现，分别是不同的量。设 A 当前为 0.90、B 为 0.80，剩一次展开机会：没有后代生成分布与成本，仅凭当前分数无法证明选 A 更好；B 可能容易改，也可能只是差。把“低分有潜力”直接当作调度规则，同样是未经证据支持的跳跃。

即使日志中 B 的最佳后代达到 0.95、A 只达到 0.92，展开次数仍影响比较：给 B 一百次机会、A 一次，再比较最大值，会混入预算优势。研究调度策略时，可以固定总预算比较完整搜索过程，或在明确条件下估计边际展开价值。R2 会计算 DGM 父代权重与 HGM 的统计口径；03 则介绍重建这类比较所需的起点、修改者和运行账本。

不同机制的结论边界

形式证明的结论受公理、效用和目标定理约束；经验比较依赖共同起点、完整成本与独立确认；探索价值还取决于操作邻域、入档规则和展开预算。这些机制解决的是不同问题，不能将 Gödel Machine、STOP/DGM 与 HGM 排成单一能力等级。本文依据 Gödel Machine v5、STOP v3、DGM v3 与 HGM v3；手算和模拟器用于解释机制，不属于这些论文的实验结果。

90% 的探索分支与 95% 的发布版本

当前分数较低的探索分支仍可能值得保留，前提是分数在相同任务与预算下测得，候选保有继续修改的能力，并能提供尚未探索的路径。继续展开它的价值取决于预期收益、成本和其他可选分支；发布版本可以保持在 95%。若两个数字来自不同评分器，则连当前表现的强弱比较也无法成立。
