实战主线 P0 · 建议第 1 周 · 8–12 小时

RepoOps Lab：把工程、评测与就业连起来

你要交付一个仓库运维 Agent 的评测与改进平台：输入故障工单，检索版本化运行手册与日志，形成有证据的处置建议；随后把它升级为可在隔离环境修复仓库的 Agent。平台负责可靠运行、独立评分、公平比较与受约束的候选搜索。贯穿始终的问题是：这个改动究竟有没有帮助，付出了多少代价？

完成状态先讲清楚本仓库提供可运行的 Python 入门实现、12 个自编公开任务、SQLite 结果存储、离线策略、可选本机 Ollama 适配器与自动测试。P1–P4、P6 的基础机制可以立即拆解。Go 分布式控制面、混合检索、Harbor 实验、GEPA 接入和递归收益属于本课程的进阶实现作业，给出接口、步骤与验收方案；不是已经上线的产品。离线策略是人为编写的规则，成绩不是 LLM 能力证据。

先定位工作，再决定学什么

本课程以已有编程和后端基础的学习者为默认读者，Python 承担 Agent 与实验层，Go 可用于后期控制面。若 Python 的类型、异常、迭代器和测试尚不熟练，先用一周重写一个 JSONL 校验器；若 HTTP、事务、索引和并发取消不熟，P5 多留一周。时间表按每周 10–15 小时估算，验收没过就顺延，不把读完章节等同于能力达标。

岗位方向招聘原文所体现的工作本项目应交付的证据适配边界
Agent / AI 应用工程围绕实际需求做原型、评测与技术解释可演示的工具循环、检索错误分析、可靠降级优先入口；具体语言和业务以目标 JD 为准
评测工程 / Research Engineer把能力定义成指标、运行评测、定位回归、分析 scaffold 影响版本化任务集、独立评分、配对实验与负结果需要补 Python 与统计，不能只有 API 包装
AI 基础设施 / 研究平台后端设计和运营可靠、可扩展的研究基础设施租约与恢复演练、容量报告、数据一致性说明后端经验可迁移；个人负载实验不能冒充生产经验

岗位样本来自 Anthropic 的 Model Evaluations、Research Infrastructure、Applied AI Research Engineer 招聘页。它们用于识别工作能力，并不代表中国招聘市场比例，也不表示这些海外岗位适合所有人的地点、资历和工作资格。检索日期为 2026-09-19，申请前重查岗位状态。

16 周主线：每一步有可交付结果

周次章节完成定义同步求职动作
1P0–P1跑通示例；写任务卡和目标岗位矩阵收集 10 个真实 JD，选择一个主方向
2–3P2–P3真实模型最小闭环；检索失败可解释录制 3 分钟演示，找同行做项目追问
4P4评分规则通过反例；第一版作品页开始小批匹配岗位投递
5–6P5队列、租约与恢复；演练重复执行准备后端系统设计答辩
7P6能从一次回归定位模型/数据/基础设施把故障复盘写成第二个项目故事
8–9P7冻结协议，完成一次真实预算对照评测岗位版本简历与模拟面试
10–11P8迁移一个任务到 Harbor，跑通 oracle 与基线阅读并提交一个小型开源修复或测试
12–13P9固定预算比较反思搜索和随机搜索用负结果解释工程取舍
14–15P10完成改进器更新消融或报告证据不足研究工程方向技术报告
16P11第三方复现、项目答辩和查漏补缺按面试反馈改材料和能力短板

赶求职时，先交付 P1–P7 的一个扎实版本；P8–P10 提供后续深度。不能为了“先进”把本应验证的单 Agent 问题提前变成多 Agent、Kubernetes 和强化学习的组合。

开源项目的具体分工

mini-SWE-agent 用来读清 model/environment/agent 的职责与循环预算；Inspect AI 用来学习任务、solver、scorer 和运行限制的分离；Harbor 承载隔离任务、验证器和基准迁移；GEPA 用轨迹反馈优化文本参数。这里只保留一条主栈，Inspect 先作为设计对照，不要求第一周同时安装四套框架。固定源码提交和精读路径见 源码与面经映射。
